## 画面②：価格比較 `/compare`

### ロジック

```typescript
// 実質価格計算
const calcRealPrice = (
  basePrice: number,
  pointRate: number,  // %
  coupon: number      // 円
) => Math.round(basePrice * (1 - pointRate / 100) - coupon)

// 購入推奨判定
const isRecommended = (realPrice: number, budget: number) => realPrice <= budget
```

### データソース

- 楽天・Yahoo!: 既存APIから取得（現在動作中）
- 価格.com: `userSettings.kakakuEnabled === true` の場合のみ表示
    - 価格は手動入力フォームから取得（自動取得は後フェーズ）
    - 入力フォームを価格比較画面上部に設置

### UI要件

- 最安ショップにバッジ表示（既存の`🏆`系アイコンを使用）
- 購入推奨の場合：緑色バナー「✅ 購入ライン以下です！」
- 予算超過の場合：赤色バナー「⚠️ 購入ラインを超えています」
- 各ショップカードに「このショップで買う →」ボタン → `/assist?shop=rakuten` 等に遷移

### 表示項目（各ショップカード）

```
ショップ名
表示価格
ポイント還元額（計算値）
クーポン割引額
実質価格（強調表示）
```

## 画面③：ワンクリックアシスト `/assist`

### URLパラメータ

```
/assist?shop=rakuten&itemId=xxxxx
/assist?shop=yahoo&itemId=xxxxx
```

### ステップ構成

```
STEP 1: 価格比較完了（自動でdone状態）
STEP 2: クーポンを取得する
  → 「クーポンページを開く」ボタン
  → 楽天: https://coupon.rakuten.co.jp/
  → Yahoo!: https://coupon.yahoo.co.jp/
  → クリック後にSTEP2をdone状態に更新
STEP 3: 商品ページへ移動
  → 「購入ページを開く」ボタン
  → 商品URLを新しいタブで開く
  → クリック後にSTEP3をdone状態に更新
STEP 4: 購入完了を記録
  → 「購入完了・記録する」ボタン
  → モーダルで購入金額・節約額を入力
  → Firestoreの`orders`に保存
  → GP+10ポイント付与
  → `/history`へ遷移
```

### Firestoreスキーマ（コレクション: `orders`への追加フィールド）

```
realPrice: number       // 実質購入価格
displayPrice: number    // 表示価格
savedAmount: number     // 節約額（表示価格 - 実質価格）
couponUsed: boolean
pointsEarned: number
```
